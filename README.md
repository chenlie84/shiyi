# 拾遗 · 试炼台

> 五行阴阳三才配装 × 掉宝鉴定 × 熔炉打造 × 回合制修仙 Roguelite

一个纯前端、无构建依赖的小游戏原型，现在按大型项目的骨架重搭过一遍：
数据、逻辑、渲染、界面四层单向依赖，逻辑层可以在 node 里裸跑。

---

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 产出单文件 dist/index.html（双击可玩）
```

URL 参数：

| 参数 | 作用 |
| --- | --- |
| `?nohelp` | 跳过开场说明 |
| `?auto` | 自动出招 + 自动配装（跑平衡、录屏用） |
| `?seed=123` | 固定随机种子，复现同一局 |

## 操作

| 干什么 | 怎么按 |
| --- | --- |
| 走位 | **WASD** / **方向键**，或者**点地面**（镜头跟着走，地宫比屏幕大） |
| 出招 | **点画面左下那排技能格**，或直接按数字键 **1**~**7** |
| 看七星详情 | 顶栏「三才 · 七星 · 行囊」→ 点七星卡片 |
| 配装 / 看行囊 | 同一个抽屉里；点卡片看详情，「炉」开熔炉、「拆」得器魂 |
| 收起抽屉 | 「收起」、Esc，或点画面空白处 |

怪从**四方**围上来，每回合朝你逼近一步；**够不着就只挪不动手** ——
所以出招之后退开，能白躲掉一回合。

## 命令

```bash
npm run check      # 结构自检：语法 / 断链 / 具名导出 / 循环依赖 / 分层越界 / 孤儿导出
npm run sim        # 无头平衡回归：5 难度 × 裸装·全投入，各 5 局
npm run sim:seed   # 同上但固定种子，数字可复现（改完数值前后对比用）
npm run verify     # check + sim，提交前跑这个
```

`npm run check` 的规矩是**可执行的**，不是文档里的口号：往 `src/data/` 里写一句
`import ... from '../game/stats.js'` 会直接红字报错、退出码 1。

## 四层结构与一票否决线

```
        ui  ──────────────►  render  ──────►  canvas
         │                      │
         │                      ▼
         └──────────────►  game  ──►  presenter（接口）
                               │
                    ┌──────────┴──────────┐
                    ▼                     ▼
                  data                   core
```

- **game 不知道 DOM 存在**。要说话就调 `render/presenter.js` 里的函数名，
  真实实现由 `main.js` 在启动时注入。于是 `tools/sim.js` 什么都不用桩，直接跑。
- **data 只有表**。往里塞逻辑的那天，就是这张表开始腐烂的那天。
- **ui 可以调一切**，但没人可以调 ui（除了 `main.js`）。
- **game 不许 import `render/*` 里除 `presenter.js` 之外的任何文件** —— 这条由 `npm run check` 守着。

法术与符的推演规则、25 式总表、构筑示例见 [`docs/SKILLS.md`](docs/SKILLS.md)，
分层与扩展点见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)，
命名与写法见 [`docs/CONVENTIONS.md`](docs/CONVENTIONS.md)，
版本脉络见 [`docs/CHANGELOG.md`](docs/CHANGELOG.md)。

## 玩法一句话

七件器分天 / 人 / 地三位，三位之间按**生 ×2、克 ×¼、阴阳济 ×½**连乘成阵；
阵定了才有七星。打怪掉宝，宝要**鉴定**才知道五行，蒙尘时佩不进三才；
熔炉三档 —— 铸（随机生词条）、淬（指定词条提一档）、引（定向引一条），
词条上限六条（前三后三）。

**地宫是一间一间隔着走的**：一层六间丹房 + 一座妖王殿。越往里越挤（2 → 3 → 4 只），
第七间只有一只妖王 —— 减伤两成多、每回合自愈，打不动就是输出不够。
妖王必掉一件仙品，妖王伏诛才下到更深一层。每过三间来一次「拾遗」三选一，妖王必给。

**法术不是选出来的，是推出来的**：每件器出一式本源法术（自己五行为体、
下一位五行为性），两者关系决定这一式是"多发"还是"穿透"还是"拐弯"。
剩下的两位是**符** —— 把分光符拍在火球上就是两发火球，把追魂符拍上去就会拐弯咬人。

## 现状

- 战斗 / 掉落 / 打造 / 经脉 / 拾遗 / 拾遗录 全链路可玩
- 25 式交叉推演法术 + 18 道符，一式最多挂 2 道；投射物真实多发、六种弹道
- 十二种招式特效 + 毛笔题字 + 掉宝光柱 + 打击停顿
- 地宫闯关：6 间丹房 + 妖王殿，五只妖王轮换（相柳 / 烛龙 / 饕餮 / 浑沌 / 太岁）
- **地宫能走**：1800 × 1280 的世界 + 900 × 560 的镜头（带死区），
  怪按四方散开再逼近，弹道横穿整屏
- 屏幕上只有顶栏 + 战场：三才 / 七星 / 行囊收进右侧抽屉，需要时才打开
- 平衡回归基线（`npm run sim:seed`，种子 7，上限 60 间，每档 8 局）：

| 难度 | 裸装 | 全投入 |
| --- | --- | --- |
| 练气·易 | 17.5 | 60（顶到上限） |
| 筑基·常 | 11.3 | 58.5 |
| 金丹·难 | 10.8 | 59.4 |
| 元婴·苦 | 5.3 | 41.3 |
| 化神·死 | 3.9 | 7.8 |

> 比 v0.9 整体宽了一点：怪现在从外面走过来，头一两个回合打不到人，
> 等于送玩家一两次免费出手。这是机制带来的，不是数值调软的。
