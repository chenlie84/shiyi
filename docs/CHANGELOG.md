## v0.10 · 地宫能走了（当前）

**目的**：从"一屏一条线"变成"一块地、一个镜头、人在里面走"。
文字面板全部收进抽屉，屏幕上只留战场。

**有了世界，也有了镜头**

- 地宫是一整块 **1800 × 1280** 的地，视口只有 **900 × 560**；
  `S.cam` 是视口左上角在世界里的位置，渲染先 `translate(-cam)` 再画世界
- 玩家有真位置（`S.px / S.py`），怪、弹道、光柱、飘字全部改成世界坐标
- **纵深排序**：人和怪按脚底 y 排，站得靠下的挡住靠上的
- 镜头带 **96px 死区** + 0.2 插值：人在中间一小块里动时镜头不动，走出去才跟。
  一直钉在正中会让人觉得"画面在动、我没动"
- 换房间时 `S.camSnap` 让镜头直接归位

**走位**

- **WASD / 方向键**推杆走，`PLAYER_SPEED = 240`；也能**点地走**（`S.moveTo`）
- 斜着走不加速，走出地面会被夹回 `FIELD`
- 输入归 `platform/input.js`，它不认识游戏状态；点地走的坐标换算由 `main.js` 注入

**怪从四方来**

- `spawnRing()` 把这一间的怪按上／下／左／右四份摊到玩家四周（整圈再随机转个角度）
- 每回合 `stepToPlayer()` 朝人挪一步（`MOB_STEP = 168`），**够不着就只挪不动手**
  （`MOB_REACH = 98`，妖王 ×1.3）—— 于是"边打边退躲掉一回合"成立
- 逼近的那一步记在 `m.dx / m.dy` 里，渲染层补一段滑行，不是瞬移
- 妖王只在玩家正前方 `spawnBoss()`

**屏幕只留战场**

- 三才阵、北斗七星、行囊三块合并成一个**右侧抽屉**（`.drawer`，点击才滑入），
  顶栏一个入口按钮「三才 · 七星 · 行囊」，带未鉴物品角标
- 顶栏改成两行：上行看数（**日期** / 层 / 房间 · 房名 / 回合 / 灵石 / 器魂 / 境界），
  下行操作（抽屉 / 经脉 / 拾遗录 / 难度 / 玩法 / 重来）
- 战报压到画面右下角半透明，走位提示在左下角、几秒后自己淡掉
- 抽屉开着时方向键让给滚动条，点地走的目标点清空；Esc 或点空白处收起

**画面**

- 地砖改成 64px 铺砖，苔与裂缝按格哈希撒；另加**火盆 / 碎石 / 骸骨**三种摆件
  （320px 大格撒，位置哈希定死 —— 走回来还是那几样，世界才有"地方"）
- 弹道**放慢**（直线 0.26s 起，远的再按距离加）并加了 9 段拖尾；
  原来 0.15s 飞完，看起来像一闪，谈不上"满屏在动"
- 招式题字倾角加大到 −0.19，飘字加了横竖向抖动（多段伤害不再叠成一坨）
- 气血槽改成像素槽：外框 + 八等分刻度 + 上亮下暗
- 页面整体垂直居中，窗口再高也不吊在顶上

**修掉一个藏了很久的 bug**

- `render/draw/background.js` 的格哈希用了普通乘法：`(a|0) * 374761393` 之后再乘
  一次 1274126177，结果远超 2^53，double 把低位全舍掉了。
  实测这个哈希**只会吐出 0 ~ 0.5**（均值 0.25），于是 `n > 0.86` 的苔永远不出现、
  `n > 0.68` 的火盆永远不出现 —— 地砖永远是"只有裂缝"的样子。
  改用 `Math.imul` 做 32 位乘法后分布均匀（均值 0.49）。

**工具**

- `npm run check` 新增**具名导出校验**：只查"文件在不在"抓不到
  `import { FOOT } from '../config.js'` 这种"文件在、名字不在"的错，
  浏览器只会静默不出图。现在会把每个文件的 export 名单收齐再对账
  （支持 `export const A=1, B=2` 这种一行多名）。
- `.workbuddy/cdp.js`、`cdp_fight.js`：用 CDP 驱动无头 Chrome 做真实时间验收
  （`--virtual-time-budget` 会把 rAF 冻住，走位测不出来）

## v0.9 · 法名成谱，秘境落地宫

**目的**：法术从"能推出来"变成"有出处"；秘境从"一波一波"变成"一间一间"。

**法名改成四字，带典故**

- 25 式全部重命名为四字（青帝缠丝 / 薪尽火传 / 息壤镇岳 / 太阿无锋 / 玄冥一泓 …），
  数据结构从字符串改为 `{ n, lore, d }`
- 五条主行各自成谱：木取丝蔓根薪荆，火取焰燎荧熔汤，土取壤岳砂泥石，
  金取刃锋阿泉薪，水取澜泉浪波泓 —— 看名就知道体是什么、性往哪边
- 出处不乱引：**同气一格引该行本神**（青帝《淮南子》、荧惑《史记·天官书》、
  息壤《山海经》、太阿《越绝书》、玄冥《礼记·月令》），
  生克各格统一归到《淮南子·天文训》的相生相克序列
- 阵技 / 劫技同步补出处：《尚书·舜典》《晋书》《道德经》《孙子》《周易·系辞》
- 卡片右上新增「详」，弹出**法术详情**：体 / 性 / 势 三栏推演 + 威力发数性效 + 出处 + 解说

**秘境改为地宫闯关**

- 一层 = **六间丹房 + 一座妖王殿**（`data/dungeon.js` 给房名与氛围句）
- 杂兵越往里越挤：第 1-2 间 2 只、3-4 间 3 只、5-6 间 4 只
- 第七间出**妖王**：单只、体型 ×1.62、减伤 22%~30%、每回合自愈 3%~4%
  五只按层轮换（相柳 → 烛龙 → 饕餮 → 浑沌 → 太岁），各有出处与一句身份说明
- **妖王必掉好东西**：4 件（一件仙品 + 一件宝品起，且都不残）+ 器魂 12 + 灵石 ×2.5，
  并必给一次「拾遗」三选一
- 顶部新增房间进度条：六方格 + 末尾菱形（妖王殿），当前格标红
- 数值曲线归一到一个数 `prog() = (层−1) × 7 + 间`，掉宝品级 / 修为 / 灵石全吃它
- `G.wave` 拆成 `G.floor` + `G.room`；`G.best` 改为最深到过第几层
- 掉落 / 修为 / 敌人出手一并重标（房间少了，单间的怪与出手要相应加重）
- 拾遗三选一节奏：每过三间一次，妖王伏诛必给一次

## v0.8 · 法术与符

**目的**：把"七技"从七个固定招式，改成"基础法术 + 改造器"。
让玩家关心的是「把这一式改成什么样」，而不是「哪一招数字大」。

- 废除 `ELEM_SKILL` / `REL_SKILL` 两套写死的招式表，改为**五行交叉推演**：
  主行（体）× 副行（性）× 两者关系（势）→ 25 式具名法术（v0.9 起改为四字名）
- 关系决定形态：泄则多发、助则加重、制则穿透、逆则折线、纯则最盛
- 新增**符**系统（18 道，5 类）：分光（+1 发）、连珠（+2 发）、追魂（追踪）、
  环流（绕身）、天坠（从天而降）、贯日（+2 穿透）、分魂（命中分裂）……
- 七星结构改为：**3 式本源法术 + 2 道符 + 阵技 + 劫技**；符位由两段关系推出来
- 一式最多挂 **2 道符**（原来只能挂 1 个辅助技），`G.links` 从数字改为数组
- 法术进入**投射物**时代：真实的多发、错峰、拖尾、穿透；轨迹六种（直线/抛射/折线/追踪/环流/天降）
- 发数衰减公式 `总威力 ∝ 发数^0.55`（现在 0.45），让"多发"是正收益但递减
- 每发独立结算暴击与命中效果，命中特性：燃 / 溅 / 缠 / 坠 / 裂
- 元婴以上额外加一档难度（`G.diff > 2` 时 mob ×1.2），让"苦"和"死"名副其实
- 新文档 `docs/SKILLS.md`：推演规则、25 式总表、18 道符表、构筑示例、平衡基线

## v0.7 · 地基重搭

**目的**：原型跑通了，但所有东西挤在一个 2400 行的 HTML 里，
改一处特效要滑三千行。这一版不动玩法，只把房子重新砌一遍。

- 单文件 2266 行 → **54 个 ES 模块**，按 data / game / render / ui / core / platform 分层
- `game/` 彻底与 DOM 解耦：`render/presenter.js` 做依赖倒置，game 只认函数名
- `platform/scheduler.js` 抽出可注入定时器，战斗流程全部改走 `delay()`
- 新增 `tools/check.js`：语法 / 断链 / 循环依赖 / 分层越界 / 孤儿导出，全部可执行断言
- 新增 `tools/sim.js` + `harness.js` + `driver.js`：**无头平衡回归**，
  不需要浏览器，每档跑 N 局，固定种子可复现
- 旧的 `onclick="xxx()"` 改为 `data-act`，事件统一在 `ui/actions.js` 里装
- 保留单文件打包：`npm run build` 仍产出可双击的 `dist/index.html`（约 120 kB，gzip 65 kB）
- 旧版单文件归档进 `legacy/`；补 README、ARCHITECTURE、CONVENTIONS

迁移验证：用同一条随机序列驱动新旧两版，`makeItem` / `makeWave` /
`calcStats` / `buildSkills` 的输出逐字节一致（仅道具自增 id 因载入起点不同而偏移）。

## v0.6 · 招式特效与毛笔题字

- 十二种施法特效，按「五行 × 招式类型」组合决定形态：
  爆闪 / 光晕 / 气罩 / 螺旋 / 冲击波 / 拖尾 / 斜斩 / 藤蔓 / 涟漪 / 火焰 / 地裂 / 水幕
- 施法时在人物上方斜题招式名，字体用 Google Fonts 的**马善政毛笔楷书**（OFL 授权），
  子集化 68 字、约 32 kB，base64 内嵌进单文件
- 题字用投影 + 二次填充，不用 `strokeText`（会把笔锋糊成黑边）
- 修：首帧怪物站位为 0，招式打到画面最左 —— 建波时就摆位
- 修：右上角掉落列表压住「破阵」题字

## v0.5 · 掉宝光柱与打击停顿

- 掉落不再直接弹列表，宝物先从地里升起一道光柱：径向渐变 + 竖向拉伸 + 矩形裁剪做柔边
- 打击停顿（hit-stop）：普通 45ms / 暴击 85ms / 击杀 100ms，
  实现方式是主循环把 `dt` 归零，**只冻渲染不冻逻辑**

## v0.4 · 词条体系转向

- 词条改用前后缀结构：前缀 ≤3、后缀 ≤3，共 6 条上限；每档 T1–T5，T1 最强
- 装备名改为「古器名 + 阴阳五行」，取自《轩辕剑》《搜神记》《封神榜》等公有领域文献
- 十二经脉图：升级得点数，点亮穴位提供加成
- 加入自动配装与平衡实测脚本（现在的 `tools/sim.js` 的前身）
