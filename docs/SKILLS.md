# 法术与符

> 一式法术 = 主行（体）× 副行（性）× 两者关系（势）。
> 符不改数值堆叠，它改这一式的**形状**。

---

## 1 七星七位

| 位 | 是什么 | 从哪来 |
| --- | --- | --- |
| 1-3 天枢·天璇·天玑 | **本源法术** | 三件器各出一式：自己五行为体，**下一位**五行为性 |
| 4-5 天权·玉衡 | **符** | 天/人、人/地 两对关系各推一道符 |
| 6 开阳 | **阵技** | 三件成阵：三生 / 双克 / 纯体 / 乱阵 |
| 7 摇光 | **劫技** | 五行缺几行，决定发数与追踪 |

地位（第 3 位）的"下一位"回头取天位 —— 三才本就是圆的，这样三件器各得一式，不多不少。

符不能单独施放。点它只会得到一句提示：挂到法术上。

## 2 三层推演

**体（主行）** —— 飞出去的是什么：

| 行 | 体 | 基础威力 | 基础弹道 | 穿透 |
| --- | --- | --- | --- | --- |
| 木 | 藤 | 1.00 | 直线 | — |
| 火 | 火球 | 1.15 | 直线（快 1.25） | — |
| 土 | 石 | 1.25 | 抛射（慢 0.80，大 1.3） | — |
| 金 | 刃 | 1.10 | 直线（最快 1.50） | 1 |
| 水 | 水箭 | 1.05 | 抛射 | — |

**性（副行）** —— 打中之后留下什么：

| 副行 | 性 | 效果 |
| --- | --- | --- |
| 木 | 缠 | 敌本回合出手 −15% |
| 火 | 燃 | 追加三成五伤害 |
| 土 | 坠 | 敌本回合出手减半 |
| 金 | 裂 | 该发伤害 +25% |
| 水 | 溅 | 波及相邻四成 |

**势（两者关系）** —— 这一式有多猛、几发、穿不穿：

| 关系 | 势 | 威力 | 发数 | 弹道 | 说法 |
| --- | --- | --- | --- | --- | --- |
| 主生副 | 泄 | ×0.90 | **+1** | — | 气泄则分，多发而散 |
| 副生主 | 助 | ×1.18 | — | — | 得助则盛，一发沉 |
| 主克副 | 制 | ×1.05 | — | — | 制则贯，穿而过 |
| 副克主 | 逆 | ×0.94 | — | **折线** | 逆则乱行，弹道歪斜 |
| 同气 | 纯 | ×1.30 | — | — | 纯则专，威力最盛 |

推演的入口只有一个函数：

```js
deriveSpell(主行, 副行) → { name, pow, proj, path, spd, pierce, size, trait, ... }
```

表里「威力」是 `pow`（体 × 势），不含攻法攻、成阵倍率、技阶与符。
这张表不是手写的，是跑 `deriveSpell()` 出来的 —— 改规则，表跟着变。

一式法术点开卡片右上的「详」，弹出来的就是这张表里的那一行：
体 / 性 / 势 三栏，加威力、发数、性效，再接出处与解说。

## 4 十八道符

一式法术最多挂 **2** 道，一道符只能挂一式。符位（4-5）由两段关系推出来，
所以**关系决定你能拿到什么方向的符**。

| 类 | 符 | 改什么 | 出自哪段关系 |
| --- | --- | --- | --- |
| 量 | **分光符** | 投射 +1，单发转薄，总量仍增 | 生 |
| 量 | **连珠符** | 投射 +2，单发更薄，总量仍增 | 生 |
| 量 | **聚风符** | 聚气成形，体积 +40%，威力 +30% | 比和 |
| 力 | **烈阳符** | 威力 +35% | 逆生 |
| 力 | **疾风符** | 弹速 +80%，威力 -5% | 克 |
| 力 | **巨灵符** | 体积 +70%，威力 +20%，弹速 -20% | 逆生 |
| 轨 | **追魂符** | 弹道改为追踪，暴击 +8% | 逆生 |
| 轨 | **折光符** | 弹道改为折线乱行，暴击 +10% | 克 |
| 轨 | **环流符** | 先绕身一周再出手，威力 +15% | 生 |
| 轨 | **天坠符** | 从天上砸下，破防 +25% | 克 |
| 轨 | **贯日符** | 穿透 +2，威力 +10% | 克 |
| 命 | **分魂符** | 命中后分裂两枚小弹（四成威力） | 比和 |
| 命 | **震魂符** | 命中溅开，波及相邻四成 | 比和 |
| 命 | **噬血符** | 命中回血 12% | 比和 |
| 命 | **凝神符** | 暴击 +18%，暴伤 +30% | 克 |
| 法 | **回春符** | 出招时回气血（两成半） | 生 |
| 法 | **护身符** | 出招时得护盾（两成半） | 生 |
| 法 | **蓄势符** | 本击六成，下一击翻倍 | 逆生 |

符有等级（跟着装备「技阶」与经脉涨，上限 Lv7）。等级放大的是**偏离 1 的那部分**：
`powMul 1.35` 在 Lv7 会变成 `1 + 0.35 × (1 + 6×0.15) ≈ 1.67`。

关系 → 符池的对应（`data/runes.js` 的 `RUNE_POOL`）：

| 关系 | 池子 |
| --- | --- |
| 生（我生它，气泄） | 分光 · 连珠 · 环流 · 回春 · 护身 |
| 逆生（它生我，得助） | 烈阳 · 巨灵 · 追魂 · 蓄势 |
| 克（互不相让） | 贯日 · 天坠 · 折光 · 凝神 · 疾风 |
| 比和（同气） | 聚风 · 震魂 · 分魂 · 噬血 |

## 5 发数与结算

发数不是白给的：

```
总威力 = 法术威力 × 发数^(1 − 0.45)
单发   = 总威力 / 发数
```

所以 `+1 发` 约 +20~37%（发数越少越赚），`+2 发` 约 +10~40%。
分光符 / 连珠符自带的 `powMul` 递减就是为了让这条曲线保持"正收益但递减"：
挂上去永远比不挂强，但不会强到必须挂。

结算顺序（`game/combat.js`）：

1. 起手特效 + 投射物生成（`spawnBolts`）
2. 每发错开 95ms 落地：选最前的存活怪 → 算伤害（0.85~1.15 浮动、破防、暴击）
3. 命中效果：裂 / 燃 / 溅 / 缠 / 坠
4. 穿透：打穿后继续打下一只，每穿一次 ×0.75
5. 全发走完 → 检查破阵，否则 240ms 后敌人还手

## 6 三种构筑

**齐射（量流）** —— 三才凑"生"，拿分光/连珠，全部挂在阵技上。
五发天降变成八发，单发薄但"燃"和"溅"能叠。适合怪多、血薄的波次。

**一柱擎天（力流）** —— 三才凑"逆生"，拿烈阳/巨灵，把单发做大。
配合土系"纯"（×1.30）与金系穿透，一发能打穿整排。

**拐弯（轨流）** —— 三才凑"克"，拿贯日/天坠/折光。
看着最不像"伤害"的一路，但破防 +25% 与折线乱行的多段命中，对高防怪最有效。

## 7 地宫与节奏

一局不是"一波一波"，是**一间一间隔着走**：

```
第 1 层 ─ 苔痕甬道 → 断碑石室 → 幽泉丹井 → 残炉丹房 → 白骨回廊 → 妖氛深殿 → 妖王殿
                                                                          ↓
                                                          妖王伏诛 → 下到第 2 层
```

| 位置 | 怪 | 掉落 |
| --- | --- | --- |
| 第 1-2 间 | 2 只杂兵 | 2 件（两成多一件） |
| 第 3-4 间 | 3 只杂兵 | 同上 |
| 第 5-6 间 | 4 只杂兵 | 同上 |
| **第 7 间 妖王殿** | **1 只妖王** | **4 件：一件仙品 + 一件宝品起，都不残；器魂 +12，灵石 ×2.5** |

妖王的两个特性构成一道门槛：

- **减伤 22%~30%**（按层轮换的五只：相柳 → 烛龙 → 饕餮 → 浑沌 → 太岁）
- **每回合自愈 3%~4% 最大气血**

打不动就是输出不够 —— 这是唯一一处"必须回去熔炉补词条"的硬墙，不是靠堆时间能磨过去的。

三选一（拾遗）的节奏：**每过三间给一次，妖王伏诛必给一次**。

数值曲线归一到一个数：`prog() = (层 − 1) × 7 + 间`。
所有掉落品级、修为、灵石都吃它，所以房间怎么排都不影响难度手感。

## 8 平衡基线

`npm run sim:seed`（种子 7，每档 8 局，上限 60 间）：

| 难度 | 裸装 | 全投入 |
| --- | --- | --- |
| 练气·易 | 17.5 | 60（顶到上限） |
| 筑基·常 | 11.3 | 58.5 |
| 金丹·难 | 10.8 | 59.4 |
| 元婴·苦 | 5.3 | 41.3 |
| 化神·死 | 3.9 | 7.8 |

裸装曲线与 v0.7（法术系统之前）基本重合，说明整套推演没有偷偷放水；
全投入明显更强，是因为旧版的 4-5 位是"不输出的辅助位"，现在换成了能改造伤害的符。
**这是这一版的设计目标，不是失衡。** 前两档的"全投入"会顶到 60 间上限，
上限之外的段位需要把上限调高才看得见。

改数值之前先存这一张表（见 `docs/CONVENTIONS.md`）。
